# Planes de tareas

Cada tarea tiene su plan aprobado **antes** de escribir código: `docs/plans/<ID>-<slug>.md`, creado desde
[`../templates/plan.md`](../templates/plan.md) (skill `start-task`). Los planes no se borran: quedan como
registro de cómo se pensó cada ítem, útil para la retrospectiva y la estimación del sprint siguiente.
